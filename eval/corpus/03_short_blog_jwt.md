# JWT(JSON Web Token) 인증 메커니즘

JSON Web Token(JWT)은 당사자 간에 정보를 JSON 객체로 안전하게 전송하기 위한 컴팩트하고 자가 수용적인(Self-contained) 표준 규격입니다.
JWT는 마침표(.)로 구분된 Header(헤더), Payload(페이로드), Signature(서명)의 세 부분으로 구성됩니다.
서버는 클라이언트가 전달한 토큰의 Signature를 비밀키로 검증함으로써 데이터의 위변조 여부를 확인하며, 서버 측 세션 저장소에 조회하지 않고도 유저의 권한을 즉시 확인할 수 있는 Stateless 인증을 구현할 수 있습니다.
단, 한 번 발급된 토큰은 만료 시간까지 임의 무효화가 어렵다는 트레이드오프가 존재합니다.
