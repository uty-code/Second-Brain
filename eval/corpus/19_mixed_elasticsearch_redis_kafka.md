# 데이터 파이프라인 트리오: Kafka, Redis, Elasticsearch

실시간 데이터 처리 플랫폼은 세 가지 컴포넌트의 유기적 분업으로 완성됩니다.
Apache Kafka는 수많은 클라이언트로부터 발생하는 대규모 로그와 비즈니스 클릭스트림 이벤트를 유실 없이 중앙에서 버퍼링하고 순서대로 스트리밍합니다.
이 스트림에서 즉각적인 집계 수치와 실시간 랭킹, 캐싱이 필요한 핫 데이터(Hot Data)는 인메모리 저장소인 Redis로 전달되어 마이크로초 단위의 초고속 조회를 담당합니다.
동시에 검색 분석과 장기적인 시계열 모니터링이 필요한 데이터는 Elasticsearch의 역색인(Inverted Index) 엔진으로 인덱싱되어 전문 검색(Full-text Search)과 대시보드 시각화에 활용됩니다.
