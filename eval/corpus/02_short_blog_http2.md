# HTTP/2 프로토콜과 멀티플렉싱

HTTP/1.1은 브라우저가 리소스를 다운로드할 때 TCP 연결마다 한 번에 하나의 요청만 처리할 수 있어, 앞선 요청이 지연되면 뒤따르는 요청이 대기하는 Head-of-Line Blocking(HOL) 문제를 겪었습니다.
HTTP/2는 단일 TCP 연결 내에서 여러 개의 양방향 독립 스트림을 동시에 주고받는 멀티플렉싱(Multiplexing) 기술을 도입했습니다.
또한 텍스트가 아닌 바이너리 프레이밍 계층(Binary Framing Layer)을 사용하고, HPACK 알고리즘으로 중복되는 HTTP 헤더를 압축하여 네트워크 대역폭 낭비를 획기적으로 줄였습니다.
