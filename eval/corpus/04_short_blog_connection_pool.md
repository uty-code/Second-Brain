# 데이터베이스 커넥션 풀(DBCP)의 역할

데이터베이스 커넥션을 맺고 끊는 작업은 TCP 3-way 핸드셰이크와 인증 절차로 인해 많은 시간과 리소스가 소모되는 무거운 연산입니다.
DBCP(Database Connection Pool)는 애플리케이션 시작 시 미리 일정 개수의 커넥션을 생성하여 풀(Pool)에 보관해 둡니다.
클라이언트 요청이 들어오면 풀에서 이미 열려 있는 커넥션을 빌려주고, 쿼리 수행이 완료되면 닫지 않고 풀에 반납하도록 관리합니다.
대표적으로 HikariCP가 널리 사용되며, 과도한 DB 부하를 방지하고 처리량을 안정적으로 유지하는 데 핵심적인 역할을 수행합니다.
