# 모던 풀스택 클라우드 스택: React 19, PostgreSQL, Kubernetes

현대적인 웹 플랫폼은 프론트엔드부터 인프라까지 서로 다른 계층의 전문 기술들이 유기적으로 결합되어 구축됩니다.
사용자 인터페이스 계층에서는 React 19의 서버 컴포넌트(Server Components)와 Actions를 활용하여 클라이언트 번들 크기를 줄이고 데이터 페칭을 서버 단에서 효율적으로 처리합니다.
영속성 계층에서는 관계형 데이터베이스인 PostgreSQL을 채택하여 복잡한 트랜잭션의 ACID 특성을 완벽히 보장하고, JSONB 자료구조를 통해 유연한 반정형 문서도 함께 수용합니다.
마지막으로 인프라 오케스트레이션 계층에서는 Kubernetes를 통해 여러 컨테이너화된 백엔드 인스턴스를 자동으로 배포하고, 트래픽에 따라 HPA(Horizontal Pod Autoscaler)로 탄력적인 오토스케일링을 수행합니다.
