# Envoy Proxy의 아키텍처와 사이드카 모델

Envoy는 대규모 서비스 지향 아키텍처(SOA)를 위해 C++로 개발된 고성능 L7 프록시 및 통신 버스입니다.
주로 쿠버네티스 서비스 메시(Istio 등) 환경에서 각 애플리케이션 파드(Pod) 옆에 사이드카(Sidecar) 형태로 배치됩니다.
Envoy는 애플리케이션 코드를 수정하지 않고도 서비스 간 mTLS 암호화, 동적 서비스 디스커버리(xDS API), 분산 추적(Distributed Tracing), 고급 로드 밸런싱(회로 차단기, 재시도, 속도 제한)을 일관되게 처리합니다.
이벤트 구동형 비동기 논블로킹 I/O 모델을 기반으로 설계되어 매우 적은 메모리 풋프린트로도 수만 개의 동시 연결을 지원합니다.
